# Security policy

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/orlear/seckit/security/advisories/new).
Do not open a public issue for them.

Include the Seckit version (`seckit --version`), the command or MCP call, and
what an attacker controls (repository content, scanner output, MCP input).

Fixes are released as new patch versions on PyPI; only the latest release is
supported.
